# Research data (not bundled)

No raw wireless recordings or processed feature tables are included in this code-only distribution. The source notebooks describe a processed dataset of 292,955 rows, but those rows have **not** been supplied as part of this GitHub package.

Put your locally available, appropriately licensed processed table at `data/processed_features.csv` to run the optional training demonstration. This location is ignored by Git so the CSV is not accidentally uploaded.

If and when you release a dataset, update this document with its **public URL**, version, original source/permissions, capture settings, integrity hash and link to a separate data dictionary. See [DATA_DICTIONARY.md](../docs/DATA_DICTIONARY.md) and [PAPER_AVAILABILITY_STATEMENT.md](../docs/PAPER_AVAILABILITY_STATEMENT.md).
