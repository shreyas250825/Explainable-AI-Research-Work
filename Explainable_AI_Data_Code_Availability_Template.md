# Data / code availability wording for the manuscript

**Use only the paragraph that matches what is actually publicly accessible.** These are templates, not declarations that a deposit has already occurred.

### Current partial-code-only release (when data are not yet public)

> Partial reference code documenting feature extraction, model architecture and evaluation steps is available at https://github.com/shreyas250825/Explanable-AI-Research-Work. The raw IQ recordings and processed research dataset are not included in this public code release. Availability of research data is subject to confirmation of provenance and redistribution permissions.

### Once a dataset has actually been deposited

> Partial reference code is available at https://github.com/shreyas250825/Explanable-AI-Research-Work. The processed dataset associated with this study has been deposited at **[INSERT VERIFIED DATASET PERMALINK, VERSION, DOI IF ANY]** under the conditions stated at that location. Raw capture recordings **[STATE ACTUAL AVAILABILITY]**. The released code does not contain the full original experimental environment.

### Items authors must confirm

- Whether the data can be redistributed, and by whom.
- Which exact processed dataset version produced the numbers in the paper.
- Whether the published GitHub code is appropriately described as **partial** and which components remain private.
- Whether the version named in the manuscript corresponds to a release/commit rather than a changing branch.
